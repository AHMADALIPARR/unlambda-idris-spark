# Support and donations

[![Donate](https://img.shields.io/badge/donate-details_pending-d97706)](https://github.com/AHMADALIPARR)

The maintainer has not provided a verified donation destination yet. The badge
links to support information and the maintainer profile; it does not initiate
a payment. No payment account, donation URL, or GitHub Sponsors enrollment is
assumed. A funding link and `.github/FUNDING.yml` can be added when the owner
confirms the destination.

You can help now by reviewing the handwritten derivations, reproducing CI,
improving specifications, or contributing tests and the open runtime/heap
implementation work. Start with [CONTRIBUTING.md](CONTRIBUTING.md).

Future donations would support project work; they would not purchase a commercial
license, security SLA, or proof of production readiness. Commercial inquiries
belong in [COMMERCIAL-LICENSING.md](COMMERCIAL-LICENSING.md).
